✅ Weekly Task Tracker

How to Use This Tracker

Recommendation: This HTML is beautiful for planning/reference, but for ACTIVE task tracking, create a simple Google Sheet with these columns:

  • Week # - Which week of the year
  • Task - What needs to be done
  • Owner - Who's responsible
  • Priority - P0/P1/P2/P3
  • Status - Not Started / In Progress / Done / Blocked
  • Notes - Any blockers or updates

Why Google Sheets? Real-time collaboration, mobile access, easy to update during your Wednesday meetings. Keep this HTML for big-picture planning!

3 Product [Task description] [Name] P0/P1/P2/P3 [#] Not Started

Priority Definitions

  • P0 - Drop Everything: App crashes, core flow broken, data loss, security issues. Fix immediately.
  • P1 - Fix This Week: Features that give wrong results, significant UX friction causing abandonment. ROI Score 70+
  • P2 - Fix Next Week: Minor UX annoyances, edge cases affecting less than 10% of users. ROI Score 40-69
  • P3 - Backlog: Nice-to-haves, visual polish. ROI Score under 40
